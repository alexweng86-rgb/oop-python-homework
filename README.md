# ООП на Python — домашние задания

Решения четырёх заданий по теме «Объектно-ориентированное программирование».

## Файлы

| Файл | Задание | Тема |
|---|---|---|
| `task1.py` | № 1 | Наследование: `Mentor` → `Lecturer`, `Reviewer` |
| `task2.py` | № 2 | Атрибуты и взаимодействие классов: `Student.rate_lecture`, `Reviewer.rate_homework` |
| `task3.py` | № 3 | Полиморфизм и магические методы: `__str__`, операторы сравнения |
| `task4.py` | № 4 | Полевые испытания: два экземпляра каждого класса и функции подсчёта средних оценок |

## Запуск

```bash
python3 task1.py
python3 task2.py
python3 task3.py
python3 task4.py
```

## Структура классов

```
AverageMixin            средняя оценка + операторы сравнения
├── Lecturer(Mentor)    лектор, хранит оценки за лекции в grades
└── Student             студент, хранит оценки за ДЗ в grades

Mentor                  name, surname, courses_attached, add_course
├── Lecturer(Mentor)
└── Reviewer(Mentor)    метод rate_homework

Student                 courses_in_progress, finished_courses, grades
                        метод rate_lecture
```

## Правила взаимодействия

- `Reviewer` выставляет оценки за домашние задания студентам.
- `Student` выставляет оценки за лекции лекторам.
- Оценка засчитывается, только если лектор закреплён за курсом и студент этот курс изучает.
- Шкала оценок — от 1 до 10.
- Методы выставления оценок возвращают `None` и изменяют состояние объекта.

## Пример вывода задания № 2

```
None
ValueError: Лектор не закреплён за этим курсом
ValueError: Студент не изучает этот курс
TypeError: Оценку за лекцию может поставить только лектору
{'Python': [7]}
```

Первые четыре строки приведены сюда как описание ожидаемого поведения:
в файле `task2.py` код повторяет текст задания, поэтому при запуске
программа останавливается на первом исключении.
